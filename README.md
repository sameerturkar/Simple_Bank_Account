# Simple Bank Account

A basic Java project that simulates simple banking operations like depositing, withdrawing, and checking balance. This project is designed to demonstrate core object-oriented programming concepts.

---

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Simple and easy-to-understand logic

---

## Tech Stack

- Java

---

## How It Works

The program uses a `BankAccount` class that handles all operations:
- Deposit adds money to the balance
- Withdraw deducts money (with basic validation)
- Balance check displays current amount
